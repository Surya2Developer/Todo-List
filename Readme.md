# To-Do List App

A simple **To-Do List** web application that uses **localStorage** to save tasks in your browser. You can add, view, and delete tasks, and they will persist even after refreshing the page.

## Features
- Add tasks you want to do
- Delete tasks when completed or no longer needed
- Tasks are stored in **localStorage**, so they persist across sessions

## Technologies Used
- HTML5
- CSS3
- JavaScript
